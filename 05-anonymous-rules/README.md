# Oppgave 05 — Anonymous Rules

**Hovedfokus:** single-expression lambdas

Bruk den samme ideen som forrige oppgave, men erstatt named method med lambdas.

Kall `PrintMatching` minst tre ganger med forskjellige regler, for eksempel:
- verdier større enn 50
- partall
- verdier mellom 20 og 40

Krav:
- Bruk single-expression lambdas som `value => ...`.
- Selve `PrintMatching` skal ikke endres mellom kallene.

## Kjøring

```bash
dotnet run
```
