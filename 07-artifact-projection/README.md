# Oppgave 07 — Artifact Projection

**Hovedfokus:** LINQ Select

Dataene er allerede ferdig modellert. Ikke bruk tid på parsing; denne oppgaven handler kun om `Select`.

Lag med LINQ:
1. en sekvens med bare artifact-navn
2. en sekvens med bare risk-tall
3. en sekvens med formatterte strings som `"Echo Stone (Moon)"`

Iterer over hvert resultat og skriv verdiene.

Ikke bruk en vanlig løkke til selve transformasjonen; løkke er bare greit for utskrift.

## Kjøring

```bash
dotnet run
```
