# Oppgave 08 — Archive Filter

**Hovedfokus:** LINQ Where

Bruk `Where` flere ganger på samme datasett for å få ulike perspektiver.

Lag separate queries for:
- alle artifacts med `Risk >= 60`
- alle fra `"Moon"`
- alle med navn som inneholder `"e"` case-insensitive

Skriv resultatene.

Poenget er ikke én vanskelig query, men repetert trening med flere predicates.
